# Original documentation

This folder holds the **original (first-generation) documentation of the LUMiNA website**, from before the current rewrite. It is kept as a historical reference. It does **not** describe how the site works today; for that, see the guides in [`docs/`](..).

| File | Content |
|---|---|
| `Lumina - Documentazione Tecnica ORIGINALE.pdf` | Original technical documentation (Italian) |
| `Editata.docx` | Edited version of the same document (Italian) |
| `Schede.7z` | Archive of the original catalogue records used as reference material |

The files are large binaries: please don't add more here. Put new documentation in `docs/` as Markdown.
